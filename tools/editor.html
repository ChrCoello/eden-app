Features

How to

Pan drag · Zoom wheel
Select click a zone
Move a corner drag a handle (orange = shared, moves both zones)
Add a corner double-click an edge of the selected zone
Delete a corner shift-click a handle
Delete many corners shift-drag a box around them, then Delete (junctions of 3+ shapes are kept)
Chemin (walkway) "Draw a chemin", click its middle line; Apply cuts it out of the zones. Needs uv run tools/serve.py. Drawing again with the same ID adds to it
Split a zone select it, "Split this zone", draw lines across it, Apply, then give each piece an ID
Merge zones select one, "Merge with…", click its neighbour: the first keeps its ID and settings
Undo Ctrl+Z
Big mistakes: move the seed in data/zone_seeds.json and re-run uv run tools/segment_zones.py instead.
